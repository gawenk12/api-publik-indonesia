# api-publik-indonesia
Kumpulan API publik dan gratis seputar data Indonesia untuk mempermudah proses development.
# 🇮🇩 API Publik Indonesia

[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg?style=flat-square)](http://makeapullrequest.com)
[![Open Source](https://img.shields.io/badge/Open%20Source-%E2%99%A5-red.svg?style=flat-square)](https://github.com/)

Kurasi lengkap *Application Programming Interface* (API) publik dan gratis yang berkaitan dengan data Indonesia. Repository ini dikelola untuk membantu para *developer* lokal dalam membangun aplikasi yang membutuhkan data spesifik Indonesia tanpa harus repot *scraping* atau membangun *database* dari nol.

## 🚀 Daftar API

### 📍 Wilayah & Demografi
| Nama API | Deskripsi | Auth | HTTPS |
|---|---|---|---|
| [API Wilayah Indonesia](https://github.com/emsifa/api-wilayah-indonesia) | Data Provinsi, Kota/Kabupaten, Kecamatan, Kelurahan | ❌ | ✅ |
| [Kode Pos API](https://github.com/Kodepos-ID/kodepos-api) | API untuk mencari kode pos di seluruh daerah Indonesia | ❌ | ✅ |

### 🕌 Agama & Waktu
| Nama API | Deskripsi | Auth | HTTPS |
|---|---|---|---|
| [API Quran](https://github.com/sutanlab/quran-api) | Data Al-Quran lengkap dengan tafsir, audio, dan terjemahan | ❌ | ✅ |
| [Jadwal Sholat](https://api.myquran.com/) | API jadwal sholat akurat untuk seluruh kota di Indonesia | ❌ | ✅ |

### 📰 Berita & Informasi
| Nama API | Deskripsi | Auth | HTTPS |
|---|---|---|---|
| [Berita Indo API](https://github.com/satyawikananda/berita-indo-api) | Menyediakan data berita dari berbagai portal media nasional | ❌ | ✅ |
| [Gempa BMKG API](https://data.bmkg.go.id/gempabumi/) | Data gempabumi terkini langsung dari situs resmi BMKG | ❌ | ✅ |

Kami sangat mengapresiasi kontribusi dari komunitas! Jika Anda mengetahui atau memiliki API publik seputar Indonesia yang belum terdaftar di sini, silakan bantu lengkapi.
